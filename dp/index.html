Fall budget requests, program by program

Mockup. Dollar amounts come from BFM and the FY 2026-27 Adopted Budget, and program descriptions from the adopted budget book. Service impact flags and type tags are sample values until bureaus begin entering them.

Adopted is the FY 2026-27 Adopted Budget requirements for each program offer (Ad Hoc Reporting Tool), including fund-level requirements such as contingency. Proposed adds the Fall requests that match your filters. Requests are from the Fall TAO D7 decision package export (3,736 line items, 271 packages, $530,518,741 net). Position costs from the personnel export ($7,417,520) are included, because the financial export leaves them out.

Requests that only change resources, such as swapping one revenue for another, don't change any program's budget, so they don't appear here.

A program offer is the level at which the adopted budget book describes services. A single request can change several programs, and a program can be changed by several requests.
